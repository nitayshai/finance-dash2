# מצפן כספי — דשבורד אישי לניהול כספים

דשבורד פרטי לניהול הכנסות, הוצאות, חסכונות והשקעות, עם תחזיות לפי תרחישי שוק ואינפלציה. המטרה: לעזור לך לחסוך יותר.

- **פרטי לגמרי:** אין שרת, אין חשבון, אין אנליטיקס ואין קריאות רשת. הנתונים נשמרים רק בדפדפן שלך.
- **מוצפן:** כל הנתונים מוצפנים בסיסמה שלך (AES-GCM 256, מפתח שנגזר ב-PBKDF2-SHA256 עם 600,000 איטרציות).
- **עובד אופליין** וניתן להתקנה כאפליקציה בטלפון (PWA).

---

## פתיחה מקומית

**הכי פשוט:** לחיצה כפולה על `index.html`. האפליקציה עובדת ישירות מהקובץ (file://).

**דרך שרת מקומי** (מאפשר גם מצב אופליין והתקנה כאפליקציה):

```bash
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: `http://localhost:8000`

> חשוב: הנתונים נשמרים לפי הכתובת. נתונים שנוצרו ב-file:// לא יופיעו ב-localhost ולהפך. כדי להעביר ביניהם, השתמש בגיבוי ושחזור.

### הרצת הבדיקות

דורש Node.js 18 ומעלה:

```bash
node --test
```

50 בדיקות לכל הלוגיקה החישובית ב-`core.js`: שנים מעוברות, 31 בחודש, תדירות רבעונית שחוצה שנה, השלמת חודשים חסרים בלי כפילויות, תשואה 0, אינפלציה גבוהה מהתשואה, דטרמיניזם של מונטה קרלו, מס רווח הון, יום תחילת חודש כלכלי, ייבוא CSV ועוד.

## העלאה לאינטרנט (קישור אישי)

הקוד יכול להיות ציבורי לגמרי, כי **הנתונים לא נמצאים בו.** הם נשמרים רק בדפדפן של מי שמשתמש באפליקציה, מוצפנים בסיסמה שלו. מי שייכנס לקישור שלך יראה אפליקציה ריקה ויתבקש ליצור סיסמה משלו. לנתונים שלך אין לו גישה.

### אפשרות א: Netlify Drop (הכי מהיר, בלי חשבון GitHub)

1. היכנס ל-https://app.netlify.com/drop
2. גרור את **כל התיקייה** (זו שמכילה את `index.html`) לחלון.
3. אחרי כמה שניות תקבל קישור בסגנון `https://random-name.netlify.app`.
4. כדי שהקישור יישמר לאורך זמן, צור חשבון חינמי ב-Netlify כשתתבקש. אפשר גם לשנות את שם האתר ב-Site settings.
5. לעדכון גרסה: Deploys ← גרור שוב את התיקייה.

### אפשרות ב: GitHub Pages

1. צור חשבון ב-https://github.com (אם אין לך).
2. לחץ **New repository**, תן שם (למשל `money`), ובחר Public. בחשבון חינמי, Pages עובד רק עם repository ציבורי, וזה בסדר כי אין בו נתונים.
3. בעמוד ה-repository: **Add file ← Upload files**, גרור את כל הקבצים והתיקיות (`index.html`, `core.js`, `app.js`, `sw.js`, `manifest.webmanifest`, `vendor/`, `icons/`, `tests/`, `README.md`) ולחץ **Commit changes**.
4. **Settings ← Pages**. תחת Source בחר **Deploy from a branch**, בחר `main` ותיקייה `/ (root)`, ולחץ Save.
5. אחרי דקה-שתיים האתר יהיה זמין ב-`https://<שם-המשתמש>.github.io/money/`

> כמה פרויקטים ב-`github.io` של אותו משתמש חולקים אחסון דפדפן. לכן כל שמות האחסון באפליקציה מתחילים בקידומת ייחודית (`matzpen-fin-v1`) כדי לא להתנגש בפרויקטים אחרים.

## התקנה כאפליקציה בטלפון

### אייפון (חשוב במיוחד!)

**למה זה חשוב:** Safari באייפון **מוחק את כל הנתונים** של אתר שלא נפתח 7 ימים. אפליקציה שהותקנה למסך הבית לא כפופה למחיקה הזו. האפליקציה מזהה אייפון ומציגה באנר תזכורת.

1. פתח את הקישור ב-**Safari**.
2. לחץ על כפתור **השיתוף** (ריבוע עם חץ למעלה).
3. בחר **"הוסף למסך הבית"** ולחץ "הוסף".
4. מעכשיו פתח את האפליקציה רק מהאייקון במסך הבית.

> הנתונים באפליקציה המותקנת נפרדים מהנתונים ב-Safari. אם כבר הזנת נתונים ב-Safari, גבה אותם שם קודם ושחזר באפליקציה המותקנת.

### אנדרואיד

ב-Chrome: תפריט ⋮ ← **"התקן אפליקציה"** או **"הוסף למסך הבית"**.

## העברת נתונים בין מכשירים

1. במכשיר הישן: **הגדרות ← גיבוי מוצפן**. יורד קובץ `matzpen-backup-YYYY-MM-DD.json`.
2. העבר את הקובץ למכשיר החדש (מייל לעצמך, WhatsApp לעצמך, Drive, AirDrop). הקובץ מוצפן, ובלי הסיסמה אי אפשר לקרוא אותו.
3. במכשיר החדש: צור סיסמה (יכולה להיות זהה או שונה), ואז **הגדרות ← שחזור מגיבוי**, ובחר את הקובץ.
4. אם הסיסמה במכשיר החדש שונה, תתבקש להזין את הסיסמה של הגיבוי.

לפני כל שחזור נשמר אוטומטית עותק של המצב הקיים, ואפשר ללחוץ **"בטל ייבוא"**.

**גיבוי בלחיצה (Chrome / Edge במחשב):** "בחר קובץ גיבוי קבוע". בחר פעם אחת קובץ, למשל בתיקיית OneDrive או Dropbox, ומאז "עדכן קובץ גיבוי" כותב אליו בלחיצה אחת.

האפליקציה מזכירה לגבות אם עברו יותר מ-14 יום מהגיבוי האחרון.

## שכחתי סיסמה — מה עושים?

הסיסמה לא נשמרת בשום מקום, וגם לא מפתח ההצפנה. זה מה שמגן על הנתונים, ולכן **אי אפשר לשחזר סיסמה שנשכחה.**

- נסה סיסמאות שאתה משתמש בהן בדרך כלל, ובדוק במנהל הסיסמאות.
- אחרי 5 ניסיונות שגויים יש השהיה שהולכת וגדלה בין ניסיון לניסיון. זה בכוונה.
- אם יש לך קובץ גיבוי ואתה זוכר את הסיסמה **שלו**: במסך הכניסה לחץ "שכחתי סיסמה" ← "אפס ומחק הכל", צור סיסמה חדשה, ושחזר מהגיבוי.
- אחרת, אין ברירה אלא לאפס ולהתחיל מחדש.

**המלצה:** שמור את הסיסמה במנהל סיסמאות, וגבה פעם בשבועיים.

## החלטות ועקרונות (תיעוד)

### כסף ותאריכים
- **סכומים נשמרים באגורות** (מספרים שלמים). מעגלים רק בתצוגה, בתחזיות (לאגורה), ובמס.
- **תאריכים מקומיים** במחרוזת `YYYY-MM-DD`. אריתמטיקת ימים לא תלויה באזור זמן או בשעון קיץ.
- **חודש כלכלי:** מתחיל ביום שנבחר (1–28) ונקרא על שם החודש שבו הוא מתחיל. למשל, עם יום 10, "נובמבר" הוא 10/11 עד 9/12.

### תנועות חוזרות
- כל מופע מקבל מזהה דטרמיניסטי `r_<סדרה>_<תאריך מתוכנן>`. בכל פתיחה משלימים מופעים חסרים עד היום, בלי כפילויות, גם אחרי חודשים בלי כניסה.
- מחיקת מופע בודד נרשמת כדילוג בסדרה, כך שהמופע לא חוזר.
- עריכת מופע בודד לא משנה את הסדרה. "המופע הזה וכל הבאים" מסיים את הסדרה הישנה ופותח חדשה מהתאריך.
- 31 בחודש בחודש קצר עובר ליום האחרון של אותו חודש. 29 בפברואר בשנה רגילה עובר ל-28.

### תחזית
- ריבית דריבית חודשית: `(1+r)^(1/12)−1`. דמי ניהול מהצבירה נגבים חודשית, ודמי ניהול מההפקדה מכל הפקדה.
- **תרחישים:** "התאמת תשואה" מוסיפה או מורידה נקודות אחוז מהתשואה הצפויה של **כל** נכס. ברירות המחדל: פסימי −2 נק' ואינפלציה 4%, בסיסי 0 ואינפלציה מההגדרות, אופטימי +1.5 נק' ואינפלציה 2%.
- **שינוי בהכנסה, שינוי בהוצאות והפקדה נוספת** מחושבים מול ממוצע 3 החודשים האחרונים (ואם אין היסטוריה, מול התנועות החוזרות). הכסף הזה נכנס ל"דלי" נזיל נפרד בתשואה של 4% (ניתן לשינוי בהגדרות) ובכפוף למס רווח הון. עודף חודשי שלא מוגדר כהפקדה לנכס לא נכנס לתחזית, כדי לא לנפח אותה.
- **אירועי חיים** מוזנים במחירי היום ומוצמדים לאינפלציה. הוצאה חד-פעמית יורדת מהדלי הנזיל.
- **מס רווח הון:** 25% על הרווח **הריאלי**, כלומר מעל בסיס עלות שמוצמד לאינפלציה. ההנחה השמרנית היא שהיתרה הנוכחית היא בסיס העלות. קרן השתלמות פטורה. לפנסיה לא מחושב מס (מיסוי קצבה מורכב ואישי).
- **נזיל מול נעול:** פנסיה נעולה עד גיל הפרישה, ונכס עם "תאריך נזילות" נעול עד התאריך. נדל"ן מוצג כלא נזיל. הפקדות לפנסיה נעצרות בגיל הפרישה.
- **מונטה קרלו:** 1,000 ריצות, תשואות חודשיות לוג-נורמליות (התוחלת נשמרת), וסטיית תקן לפי רמת סיכון: נמוכה 3%, בינונית 10%, גבוהה 18%, או ערך ידני לכל נכס. **זעזוע שוק משותף** לכל הנכסים בכל חודש (מתאם מלא, הנחה שמרנית). ה-seed קבוע, כך שאותם קלטים נותנים תמיד אותה תוצאה. החישוב רץ בחלקים כדי שהממשק לא ייתקע (Web Worker לא עובד אמין ב-file://).
- **FIRE:** יעד = הוצאה שנתית חלקי שיעור משיכה בטוח (ברירת מחדל 4%). הגיל מחושב לפי השווי **הריאלי** הכולל בתרחיש הנבחר.

### תובנות
מוצגות רק כשיש מספיק נתונים. למשל, השוואה לממוצע דורשת 3 חודשי היסטוריה, וחריגה מוצגת רק מעל 20% וגם מעל ₪200.

### אבטחה ואחסון
- **IndexedDB** (`matzpen-fin-v1-db`), ואם לא זמין, **localStorage** עם אותה קידומת.
- כל שמירה מצפינה מחדש עם **IV אקראי חדש**. ה-salt אקראי (16 בתים) ונוצר מחדש בכל החלפת סיסמה.
- הסיסמה והמפתח לא נשמרים. המפתח קיים רק בזיכרון. נעילה (ידנית, או אוטומטית אחרי X דקות בלי פעילות) שומרת שינויים ממתינים ואז מוחקת מהזיכרון את המפתח, את הנתונים ואת המסך.
- לא מוצפנים רק: ערכת הצבעים (כדי שמסך הכניסה יוצג נכון) ומונה הניסיונות השגויים.
- Content-Security-Policy חוסם כל חיבור רשת (`connect-src 'none'`), ואין פונטים או סקריפטים חיצוניים.
- **schemaVersion** עם פונקציות מיגרציה. בייבוא נבדקים מבנה הקובץ, גרסת הסכמה ותקינות הנתונים לפני שמשהו נדרס.

### גרפים
Chart.js 4.6.1 שמור מקומית ב-`vendor/`. המקרא וה-tooltips מוצגים מימין לשמאל, וציר הסכומים מימין. **ציר הזמן נשאר משמאל לימין** (מוקדם משמאל), כמקובל בגרפים פיננסיים גם בממשקים בעברית.

```

core.js                 לוגיקה חישובית טהורה (window.FinanceCore / module.exports)
app.js                  ממשק, אחסון, הצפנה, ניווט ומסכים
vendor/chart.umd.min.js Chart.js 4 (מקומי, בלי CDN)
manifest.webmanifest    הגדרות PWA
sw.js                   Service worker (נרשם רק ב-http/https)
icons/                  אייקונים (SVG + PNG)
tests/core.test.js      בדיקות (node --test)
```
